# [`spTools`](https://github.com/cwendorf/spTools/)

## Introduction

Users of `statpsych` may need additional analyses, vector-based inputs, or more consistent output formatting. `spTools` supplies these extensions while keeping workflows compatible with `statpsych`.

- [Overview](#overview)
- [Resources](#resources)

---

### Overview

`spTools` extends Doug Bonett's `statpsych` package in three ways: it adds selected calculations, wraps existing procedures to accept vectors instead of individual arguments, and provides tools to standardize or reformat output. Comparison wrappers also combine related confidence intervals into a single workflow.
