# [`spTools`](https://github.com/cwendorf/spTools/)

## Articles

This section contains vignettes for `spTools`. Focus here is on demonstrating how `spTools` adds to the features of `statpsych`.

### Vector Input Wrappers

`spTools` offers wrappers for existing `statpsych` functions that instead use vector input for parameters.

- [Confidence Intervals for Means](./spToolsMeans.md): Compares nonvectorized and vectorized methods for calculating confidence intervals for means and their differences.
- [Confidence Intervals for Correlations](./spToolsCorrelations.md): Compares nonvectorized and vectorized methods for calculating confidence intervals for correlations and their differences.
- [Confidence Intervals for Proportions](./spToolsProportions.md): Compares nonvectorized and vectorized methods for calculating confidence intervals for proportions and their differences.

### Comparison Wrappers

`spTools` provides wrapper functions that automate the calculation of all confiddence intervals involved in comparisons and contrasts.

- [Confidence Intervals for Mean Comparisons](./spToolsMeansComparisons.md): Examines manual vs wrapper methods for calculating confidence intervals for mean comparisons.
- [Confidence Intervals for Correlation Comparisons](./spToolsCorrelationsComparisons.md): Examines manual vs wrapper methods for calculating confidence intervals for correlation comparisons.
- [Confidence Intervals for Proportion Comparisons](./spToolsProportionsComparisons.md): Examines manual vs wrapper methods for calculating confidence intervals for proportion comparisons.
